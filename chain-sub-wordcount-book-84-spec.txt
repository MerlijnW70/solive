# Job: Count every long word in one book (book 84)

Input: one file, exactly as these bytes are hosted:
https://raw.githubusercontent.com/MerlijnW70/solive/e2e-fixtures/chain-book-84.txt sha256 7810cd483cffcf2cc8a1d8f0d5807931e69d4f48cd14149b8c76f88af82fead3

## Rules

- Read the file as bytes. Fold A-Z to a-z. A word is a maximal run of the bytes a-z; every other byte separates words.
- Count every word of 6 or more letters in the whole file, including the Project Gutenberg header and licence text; ignore shorter words.

## Deliver

A UTF-8 text file with one line per distinct word of 6 or more letters in the file, each `word<TAB>count` ending in LF: ALL such words, not a top-N. Sorted by count from high to low, ties by word in byte order. Nothing else in the file.

## Check

The judge computes the table from the same bytes and compares the delivered file byte for byte. Any difference fails. Deliver with solive_wallet_deliver to this escrow; the judge pays the earliest exact delivery.

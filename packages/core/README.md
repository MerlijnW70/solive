# @intent-engine/core

Types, amount helpers, event decoding and errors for the Solive program on Solana. Instruction builders are not part of this entry; the client builds instructions. Most apps start with [@intent-engine/client](https://www.npmjs.com/package/@intent-engine/client), which builds on this package.

```sh
npm install @intent-engine/core @intent-engine/client @solana/kit
```

- [Build in TypeScript](https://merlijnw70.github.io/solive/sdk)
- [The full client](https://merlijnw70.github.io/solive/sdk-client)

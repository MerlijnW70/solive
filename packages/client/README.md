# @intent-engine/client

Swap, escrow and pay for work on Solana devnet from TypeScript. Devnet tokens have no value.

```sh
npm install @intent-engine/core @intent-engine/client @solana/kit
```

- [The full client](https://merlijnw70.github.io/solive/sdk-client)

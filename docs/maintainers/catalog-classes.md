# Vulnerability classes

Every class in Coral's [sealevel-attacks](https://github.com/coral-xyz/sealevel-attacks), the [program security course](https://solana.com/developers/courses/program-security/security-intro) and the [Helius security guide](https://helius.dev/blog/a-hitchhikers-guide-to-solana-program-security), mapped to every instruction of `programs/intent_engine` where it can apply.

Each row names the class, its first source (the class list below links every source), the instruction, whether the class applies, the reason in our code, and the evidence. A row that applies cites the tests that run the attack and see it refused, in the forms [threat-model.md](threat-model.md) uses, plus `file:<path>` for a document. A row that does not apply names the file and mechanism that rule it out. `every other instruction` covers the instructions of that class without a row of their own. `packages/cli/test/catalog-classes.test.ts` fails when a cited test, file or instruction is missing.

The tests in `tests/svm/tests/catalog_class_*.rs` build a valid instruction, apply one attack to it, assert the exact refusal, then send the unchanged instruction and see it succeed.

## Claim board lifecycle

Every test runs each state on an open board and on a listed board; on the listed board a worker off the list is refused with `NotListed`. ### The cooldown on every path that grants the claim

`claim_job`, the hand-over in `drop_claim` and `advance` grant the claim by one rule, `Cooldown::check` in `crates/intent-core/src/claim.rs`: a worker that dropped may not hold the job again before its term ends. ## Token-2022 recipient accounts

Each payout path against a Token-2022 receiving account with one owner or issuer setting, on a mint with interest-bearing, metadata-pointer and freeze authority. Amounts are checked to the base unit. A refusal moves nothing and leaves the escrow releasable or refundable.

A co-author's share that its canonical account cannot accept is held in the vault for that co-author to claim with `claim_held`; the escrow cannot be closed while a share is held until a year after it expires. A protocol fee its account cannot accept is withheld like the judge and partner fees. No account's setting stops another recipient's payout.

## Mandate limits, lanes and stops

Each limit of `Limits::admit`, each nonce lane case and each way a mandate stops, run through `create_intent_by_agent` at the limit and one step past it. Amounts are checked to the base unit. A refusal moves no tokens and leaves `spent` and `intents` unchanged. The CLI and MCP tools refuse what the program refuses, before anything is simulated or signed, with the program's error and hint.

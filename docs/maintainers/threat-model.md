# Threat model

Who can attack what, what stops them, and what is still open. Report a vulnerability as [SECURITY.md](../../SECURITY.md) describes, never in a public issue.

Every `mitigated` or `partial` row names the tests, proofs, fuzz targets or CI jobs that show it, and `packages/cli/test/threat-model.test.ts` fails if one of them does not exist. An `open` row names the planned control first and cites evidence only for the part already in place. Evidence forms:

- `rust:<file>::<fn>`: a Rust test in `tests/svm/tests` or `crates/intent-core/tests`
- `kani:<harness>`: a Kani proof in `tests/proofs`
- `ts:<package>:<title>`: a vitest test in the test directory of that package
- `fuzz:<target>`: a fuzz target in `crates/intent-core/fuzz/fuzz_targets`
- `ci:<job>`: a job in `.github/workflows/ci.yml`

## Assets

- **escrow**: the input tokens an intent holds in its vault until it fills, is cancelled or expires.
- **fees**: the protocol fee, partner share, agent fee, relayer fee and crank bounty.
- **judge fee**: what a proof escrow pays its judge out of the escrow.
- **upgrade authority**: the key that can replace the program.
- **admin**: the config admin role, which sets fees, pauses and the guardian.
- **keys**: the private keys of owners and of every role.
- **spec**: the job spec a proof escrow commits by hash, and the URL it is published at.
- **delivery**: a worker's artefact and the hash it announces to the judge.
- **npm packages**: `@intent-engine/core`, `@intent-engine/client`, `@intent-engine/solver` and `@intent-engine/cli`.

## Actors and their powers

- **owner**: signs creates, cancels and mandates for their own tokens.
- **solver**: fills open intents with its own tokens, directly or by flash fill.
- **worker**: builds a delivery for a proof escrow and announces its hash.
- **judge**: the attestor an attested or proof escrow names; runs the check and signs the release.
- **relayer**: submits an intent the owner signed offline and pays its transaction costs.
- **agent**: creates intents for an owner within a mandate the owner granted.
- **partner**: earns a share of the fee on intents that name it.
- **cranker**: anyone who expires or closes intents for the crank bounty.
- **admin**: holds the config admin key; sets fees, pauses and the guardian.
- **guardian**: may raise pause flags.
- **RPC node**: answers every read and forwards every transaction the tools send.
- **supply chain**: npm, crates, GitHub Actions and the build that turns source into the program and the packages.
- **anyone**: any key, with no role.

# Incident catalog

Every incident, attack class and checklist item in two public collections of Solana incidents, mapped to Solive: the program, the client SDK, the CLI and MCP wallet, the solver, key handling and the release pipeline. The collections are Helius's history of Solana hacks and CertiK's overview of 2022 Solana exploits.

Each row names its source, the pattern in one sentence, where it would hit Solive, whether it applies and why, and the tests or checks that prove resistance. A row that does not apply names the file whose mechanism rules it out. Evidence uses the forms of the [threat model](threat-model.md), plus `file:<path>` for the code a reason rests on and `threat:<id>` for a threat model row. `packages/cli/test/catalog/incident-citations.test.ts` fails when a cited test, file, job or row does not exist, when a row lacks its reason or evidence, and when an incident of either source has no row.

Tests written for this catalog live in `tests/svm/tests/catalog_incident_*.rs` (program) and `packages/cli/test/catalog` (key handling and supply chain).

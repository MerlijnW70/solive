# Catalog: arithmetic, economic and logic checks

Each row maps one item of an audit checklist to the engine path where it can strike, and names the test, proof or CI job that shows the engine resists it. The sources are the [QuillAudits Solana audit checklist](https://www.quillaudits.com/research/solana-audit-checklist) and the [Helius guide to Solana program security](https://helius.dev/blog/a-hitchhikers-guide-to-solana-program-security).

Evidence uses the forms of [threat-model.md](threat-model.md): `rust:<file>::<fn>`, `kani:<harness>`, `ts:<package>:<title>`, `fuzz:<target>` and `ci:<job>`. `packages/cli/test/catalog-economics.test.ts` fails when a cited artefact does not exist, when an applicable row cites nothing, when a row that does not apply names no file of this repository, or when a checklist item or engine path has no row.

Applies is `yes`, or `no:` followed by the mechanism in our code that rules the item out.

# Job: Full count of four-letter words in one book (part B)

Count words in the file below, exactly as these bytes are hosted.

1. https://raw.githubusercontent.com/MerlijnW70/solive/e2e-fixtures/chain-book-2701.txt sha256 b5e88b71a1cda068e9ab1d94344c9d932338ba6da1a66def97a1aecd9cfcc87d

## Rules

- Read each file as bytes. Fold A-Z to a-z. A word is a maximal run of the bytes a-z; every other byte separates words.
- Count every word of exactly 4 letters over the whole file, including the Project Gutenberg header and licence text; ignore all other words.

## Deliver

A UTF-8 text file with one line per distinct word of exactly 4 letters that occurs at least once (every such word, not a top list), each `word<TAB>count` ending in LF, sorted by count from high to low, ties by word in byte order. Nothing else in the file: no header, no blank lines, no BOM.

## Check

The judge computes the table from the same bytes and compares the delivered file byte for byte. Any difference fails. This job takes claims: claim it before working on it.

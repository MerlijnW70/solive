# Job: Full count of four-letter words in two books (part A)

Count words across both files below together, exactly as these bytes are hosted.

1. https://raw.githubusercontent.com/MerlijnW70/solive/e2e-fixtures/chain-book-1342.txt sha256 3f6bb9d6f78e0293b56acd4714dd68cb7d6d1d293402031ce9d5a216bcaf9d75
2. https://raw.githubusercontent.com/MerlijnW70/solive/e2e-fixtures/chain-book-84.txt sha256 7810cd483cffcf2cc8a1d8f0d5807931e69d4f48cd14149b8c76f88af82fead3

## Rules

- Read each file as bytes. Fold A-Z to a-z. A word is a maximal run of the bytes a-z; every other byte separates words.
- Count every word of exactly 4 letters over both files combined, including the Project Gutenberg header and licence text; ignore all other words.

## Deliver

A UTF-8 text file with one line per distinct word of exactly 4 letters that occurs at least once (every such word, not a top list), each `word<TAB>count` ending in LF, sorted by count from high to low, ties by word in byte order. Nothing else in the file: no header, no blank lines, no BOM.

## Check

The judge computes the table from the same bytes and compares the delivered file byte for byte. Any difference fails. This job takes claims: claim it before working on it.
